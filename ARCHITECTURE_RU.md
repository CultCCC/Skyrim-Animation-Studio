## 2. Рекомендуемый стек: Rust поверх Aether

**Почему не форк SSE Animation Previewer:** нужен .NET 8 SDK (не установлен), WPF-интерфейс пришлось бы переписать целиком (а именно он вам и неудобен), кодовая база чужая и большая. Его документацию используем как справочник правил (Precision, PIE, OAR) — лицензии совместимы (оба GPL-3).

**Почему Aether:** 70% «тяжёлого» уже есть и проверено на ваших данных — NIF, skinning, текстуры, BSA, ESP, частицы VFX (требование 4 прямо говорит брать рендер оттуда). egui — immediate-mode, как ImGui в DS Anim Studio, поэтому похожий интерфейс делается естественно (докинг через `egui_dock`).

Оригинал `Skyrim VFX editor` не трогаем: студия — отдельный Cargo-workspace, нужные крейты Aether (nif, core, codecs) и serde-hkx лежат копией в `vendor/`.

## 3. Архитектура

```
sds-anim-studio (workspace)
├─ crates/vfs        MO2: profile\modlist.txt → упорядоченные корни mods\* + overwrite + BSA; plugins.txt → load order
├─ crates/hkx        HKX: скелет (hkaSkeleton), анимация (spline + interleaved декод), аннотации чтение/запись,
│                    extracted motion; поверх serde-hkx; запасной путь записи — hkanno64 (через temp-папку без [скобок])
├─ crates/anno       Модель аннотаций: парсер по типам (Precision, PIE, SCAR, MCO/BFCO, AMR, SDS_NPC_*, SoundPlay, прочие)
│                    ↔ текст; схема параметров для инспектора; валидация (опечатки, порядок Start/End)
├─ crates/actor      NPC из ESP: NPC_ → RACE (skeleton.nif/hkx, тело), WNAM/OTFT/LVLI (броня), инвентарь (оружие),
│                    FaceGen-голова из facegendata; ARMA _0/_1 по весу; вешает оружие на WEAPON/holster
├─ crates/sim        Детерминированный «прогон» клипа по времени t:
│   ├─ rootmotion    animmotion/animrotation (AMR-формат) относительно текущего направления NPC + SDSCombat-модификаторы
│   ├─ precision     капсулы Collision_* по правилам Precision 2.0.4 (+ settings.ini из сборки)
│   ├─ pie           PIE.$Alias → ini → @CAST/@APPLYSPELL/@SGVF… → SPEL/MGEF → NIF арта → частицы Aether
│   └─ sdscombat     TargetLockOn/TurnSpeed/Off/StopRotation/Reset, ReachTarget ref|min|max|arrive (× масштаб NPC);
│                    включается, только если в VFS найден SKSE\Plugins\SDSCombat.dll
├─ crates/oar        Библиотека OAR: обход OpenAnimationReplacer\**\config.json/user.json, дерево мод → сабмод → клипы,
│                    условия/приоритеты (только показ); экспорт сабмода в новую папку-мод
└─ app               egui + wgpu, докинг в стиле DS Anim Studio
```

Главный принцип: **всё, что видно в рендер-окне, — функция `(клип, t, настройки сцены)`**. Перемотка назад/вперёд и покадровый шаг тогда работают честно, без накопления ошибок (так же сделано в DSAS и в превьюере).

Редактирование на таймлайне: перетаскивание, копирование, удаление, вставка по шаблону (меню «добавить Precision-атаку», «добавить ReachTarget» и т.д.), привязка к кадрам, undo/redo. `animmotion/animrotation` по умолчанию свёрнуты в одну строку-кривую, чтобы не было 100 строк.

### Сохранение
- Изменённый клип пишется **не поверх оригинала**, а в выбранную папку-мод вывода (по умолчанию `Output\SDS Anim Studio Output` рядом с exe) с тем же относительным путём — её подключаете в MO2 выше оригинала.
- Перед записью — проверка «прочитал → записал → прочитал заново, аннотации совпадают, трек анимации байт-в-байт».

### SCAR-режим (требование 7)
Вкладка «SCAR»: вид сверху, круг вокруг NPC, для каждой `SCAR_ActionData` — сектор от MinDistance до MaxDistance и от StartAngle до EndAngle, цвет по Type (RA/RPA/…), подпись IdleAnimation/Chance. Сектора тянутся мышью (радиусы, углы), поля дублируются в инспекторе. Можно поставить «манекен игрока» и увидеть, какие действия он активирует. Пишется обратно в аннотацию JSON. Значения из `SCAR.ini` — фоном (глобальные дистанции).

## 5. Риски

- **Декод spline-анимации** — самая рискованная часть; сверяю позы с SSE Animation Previewer и hkxPoser на одних и тех же клипах.
- **Запись hkx через serde-hkx** может не дать байт-идентичный трек. Тогда запасной путь — hkanno64 (он уже работает в `add_reach_target.py`). Решаю автоматически по проверке round-trip.
- **PIE/FX** — эффекты бывают «скриптовые»; показываю, что резолвится, остальное — в диагностике, как в превьюере.
- Пол/расса/скелет кастомных боссов (SNEK, Малления) — нужен правильный skeleton.hkx из их папки; беру его из пути клипа (`meshes\actors\<x>\animations` → `<x>\character assets\skeleton.hkx`).
